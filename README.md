# My Portfolio

> A modern, responsive personal portfolio website showcasing my work, skills, projects, and professional journey.

[![GitHub](https://img.shields.io/badge/GitHub-frankpatel1-181717?style=flat\&logo=github)](https://github.com/frankpatel1)

## Overview

This repository contains my personal portfolio website, designed to present my professional profile, projects, technical skills, and experience through a clean and modern web interface.

The portfolio is built with a focus on:

* Modern and minimal visual design
* Responsive layouts across desktop, tablet, and mobile
* Smooth and intuitive user experience
* Clear presentation of projects and skills
* Performance and accessibility
* Easy navigation and maintainable structure

## ✨ Features

* Responsive portfolio layout
* Modern UI and visual design
* Hero/introduction section
* About section
* Skills and technologies
* Project showcase
* Professional experience and background
* Contact section
* Responsive navigation
* Optimized assets
* GitHub Actions workflow

## 🛠️ Built With

The project uses web technologies including:

* CSS3

* Git & GitHub
* GitHub Actions

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/frankpatel1/My-Portfolio.git
```

### Navigate to the project

```bash
cd My-Portfolio
```

### Run locally

Because this is a web portfolio, you can open `index.html` directly in your browser or use a local development server.

For example, with VS Code, install the **Live Server** extension and open the project using Live Server.
